### 一、教学目标

通过本章学习，学生应具备以下核心能力：

1. **Matplotlib基础绑图**：掌握figure/axes对象模型，能够创建折线图、柱状图、散点图、饼图等基本图形，并进行标题、标签、图例、颜色等参数设置。

3. **描述统计可视化**：能够用箱线图识别异常值、用直方图和核密度图展示分布形态、用小提琴图比较分组分布。
4. **关系可视化**：能够用散点图展示两变量关系、用散点图矩阵展示多变量两两关系、用热力图展示相关系数矩阵。

### 三、重点与难点

**重点**：
- Matplotlib的figure/axes对象模型（面向对象绑图 vs pyplot状态机绑图）
- 箱线图的五数概括解读与异常值识别
- 热力图的参数设置（annot、cmap、center）
- 散点图矩阵（pairplot）的使用与解读

**难点**：
- Seaborn的figure-level函数（如catplot、relplot）与axes-level函数（如boxplot、scatterplot）的区别
- 多子图布局的精细调整（gridspec、subplot_mosaic）
- 配色方案的选择（Sequential vs Diverging vs Qualitative）

**化解建议**：
1. 建议初学者先掌握axes-level函数（如`sns.boxplot`），再学习figure-level函数（如`sns.catplot`）。axes-level函数更灵活，可以精确控制绑图位置。
2. 配色方案的选择原则：**连续型数据用Sequential**（如"viridis"、"Blues"），**有中心值的数据用Diverging**（如"RdBu_r"、"coolwarm"），**分类数据用Qualitative**（如"Set2"、"tab10"）。

### 3.1 多元数据可视化准备

#### 3.1.1 Matplotlib基础

**【业务场景引入】**

在大宗商品分析中，可视化是沟通数据洞察的核心工具。一个优秀的图表可以：
- 一眼看出铜价的趋势方向和波动幅度
- 直观比较不同品种的收益分布差异
- 揭示变量之间的相关模式

Matplotlib是Python最基础的绑图库，几乎所有其他可视化库（Seaborn、Plotly）都建立在它的基础之上。

**（1）两种绑图风格**

```python
# 风格1：pyplot状态机风格（简单但不灵活）
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [4, 5, 6])
plt.title('简单折线图')
plt.show()

# 风格2：面向对象风格（推荐，更灵活）
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [4, 5, 6])
ax.set_title('简单折线图')
plt.show()
```

**推荐使用面向对象风格**，因为可以精确控制每个子图的位置和大小，便于创建多子图布局，代码逻辑更清晰。

**（2）figure与axes对象的关系**

- **figure**：整个画布，可以包含一个或多个axes
- **axes**：一个绑图区域，包含坐标轴、数据、标题等

```python
import matplotlib.pyplot as plt
import numpy as np

# 创建2行3列的子图布局
fig, axes = plt.subplots(2, 3, figsize=(15, 10))

# 在指定子图上绑图
x = np.linspace(0, 2*np.pi, 100)
axes[0, 0].plot(x, np.sin(x), color='steelblue', linewidth=2, label='sin(x)')
axes[0, 0].plot(x, np.cos(x), color='coral', linewidth=2, linestyle='--', label='cos(x)')
axes[0, 0].set_title('三角函数', fontsize=14)
axes[0, 0].set_xlabel('x', fontsize=12)
axes[0, 0].set_ylabel('y', fontsize=12)
axes[0, 0].legend(loc='upper right')
axes[0, 0].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

**（3）中文字体设置**

```python
# Windows系统
plt.rcParams['font.sans-serif'] = ['SimHei']
# macOS系统
# plt.rcParams['font.sans-serif'] = ['Arial Unicode MS']
# 解决负号显示问题
plt.rcParams['axes.unicode_minus'] = False
```

**（4）常用图形元素设置**

| 元素 | 设置方法 | 示例 |
|------|----------|------|
| 标题 | `ax.set_title()` | `ax.set_title('铜价走势', fontsize=14)` |
| x轴标签 | `ax.set_xlabel()` | `ax.set_xlabel('日期', fontsize=12)` |
| y轴标签 | `ax.set_ylabel()` | `ax.set_ylabel('价格（元/吨）', fontsize=12)` |
| 图例 | `ax.legend()` | `ax.legend(loc='upper left', fontsize=10)` |
| 网格线 | `ax.grid()` | `ax.grid(True, alpha=0.3)` |
| x轴范围 | `ax.set_xlim()` | `ax.set_xlim(0, 100)` |
| y轴范围 | `ax.set_ylim()` | `ax.set_ylim(50000, 80000)` |
| 刻度旋转 | `ax.tick_params()` | `ax.tick_params(axis='x', rotation=45)` |

#### 3.1.2 Seaborn高级可视化

Seaborn是基于Matplotlib的高级统计图形库，提供了更美观的默认样式和更简洁的API。

**（1）Seaborn的API风格**

| 类型 | 特点 | 示例 | 适用场景 |
|------|------|------|----------|
| **axes-level** | 在指定axes上绑图 | `sns.boxplot(ax=ax)` | 需要精确控制位置 |
| **figure-level** | 创建独立图形 | `sns.catplot(kind='box')` | 快速探索性分析 |

```python
# axes-level函数（推荐）
fig, ax = plt.subplots(figsize=(8, 6))
sns.boxplot(x='品种', y='收益率', data=df, ax=ax)
ax.set_title('各品种收益率箱线图')

# figure-level函数
g = sns.catplot(x='品种', y='收益率', data=df, kind='box', height=6, aspect=1.5)
g.fig.suptitle('各品种收益率箱线图', y=1.02)
```

**（2）Seaborn主题设置**

```python
sns.set_theme(style="whitegrid", palette="muted", font_scale=1.2)
# style选项：darkgrid, whitegrid, dark, white, ticks
# palette选项：muted, pastel, bright, deep, colorblind
```

#### 3.1.3 配色方案选择

| 配色类型 | 适用场景 | 示例 |
|----------|----------|------|
| Sequential（连续型） | 连续数据 | "viridis", "Blues" |
| Diverging（发散型） | 有中心值的数据 | "RdBu_r", "coolwarm" |
| Qualitative（分类型） | 分类数据 | "Set2", "tab10" |

### 3.2 条图或柱图

#### 3.2.1 简单条形图

```python
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

products = ['铜', '铝', '锌', '铅', '镍', '黄金', '白银', '原油']
volumes = [125000, 89000, 67000, 45000, 52000, 98000, 76000, 150000]

fig, axes = plt.subplots(1, 2, figsize=(14, 6))

colors = plt.cm.Set2(np.linspace(0, 1, len(products)))
axes[0].bar(products, volumes, color=colors, width=0.6, edgecolor='white', linewidth=0.5)
axes[0].set_title('各品种月均成交量', fontsize=14)
axes[0].set_ylabel('成交量（手）')

for i, (name, vol) in enumerate(zip(products, volumes)):
    axes[0].text(i, vol + 2000, f'{vol/10000:.1f}万', ha='center', fontsize=9)

sorted_idx = np.argsort(volumes)
axes[1].barh([products[i] for i in sorted_idx], [volumes[i] for i in sorted_idx],
             color=colors[sorted_idx], height=0.6)
axes[1].set_title('各品种月均成交量（水平）', fontsize=14)
axes[1].set_xlabel('成交量（手）')

plt.tight_layout()
plt.show()
```

### 3.3 描述统计及箱尾图

#### 3.3.1 箱线图

**箱线图的五数概括**：最小值、Q1（25%分位数）、中位数、Q3（75%分位数）、最大值。IQR = Q3 - Q1，超出Q1-1.5×IQR或Q3+1.5×IQR的点为异常值。

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False
np.random.seed(42)

n = 250
df = pd.DataFrame({
    '铜ETF': np.random.normal(0.0003, 0.018, n),
    '原油ETF': np.random.normal(0.0002, 0.022, n),
    '黄金ETF': np.random.normal(0.0001, 0.010, n),
    '白银ETF': np.random.normal(0.00015, 0.020, n),
    '农产品ETF': np.random.normal(0.0001, 0.012, n)
})

fig, axes = plt.subplots(1, 3, figsize=(18, 6))

df.boxplot(ax=axes[0], grid=False)
axes[0].set_title('Pandas箱线图', fontsize=14)
axes[0].set_ylabel('日收益率')
axes[0].axhline(y=0, color='red', linestyle='--', alpha=0.5)

df_melt = df.melt(var_name='品种', value_name='收益率')
sns.boxplot(x='品种', y='收益率', data=df_melt, ax=axes[1], palette='Set2')
axes[1].set_title('Seaborn箱线图', fontsize=14)
axes[1].axhline(y=0, color='red', linestyle='--', alpha=0.5)

sns.violinplot(x='品种', y='收益率', data=df_melt, ax=axes[2], palette='Set2', inner='box')
axes[2].set_title('Seaborn小提琴图', fontsize=14)
axes[2].axhline(y=0, color='red', linestyle='--', alpha=0.5)

plt.tight_layout()
plt.show()
```

**小提琴图与箱线图的区别**：
- **箱线图**：只展示五数概括
- **小提琴图**：在箱线图基础上叠加核密度估计曲线，展示分布形状

### 3.4 变量间的关系图

#### 3.4.1 散点图

```python
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

axes[0].scatter(df['铜ETF'], df['原油ETF'], alpha=0.4, s=20, color='steelblue')
```

#### 3.4.2 散点图矩阵（PairPlot）

```python
from sklearn.datasets import load_iris

iris = load_iris()
df_iris = pd.DataFrame(iris.data, columns=iris.feature_names)
df_iris['species'] = pd.Categorical.from_codes(iris.target, iris.target_names)

g = sns.pairplot(df_iris, hue='species', diag_kind='kde',
                 plot_kws={'alpha': 0.6, 's': 30}, palette='Set2')
```

**散点图矩阵的解读**：
- **对角线**：各变量的核密度分布图
- **非对角线**：两两变量的散点图
- 可以同时看到各变量的分布形态、变量间的相关关系、不同类别的分离程度

```python
categories = ['经济发展', '教育水平', '医疗条件', '环境质量', '科技创新', '基础设施']
```

### 实战案例3-1：大宗商品市场综合可视化报告

**【业务场景】** 你需要为基金经理制作一份大宗商品市场的月度可视化报告。

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False
sns.set_theme(style="whitegrid", palette="muted")
np.random.seed(42)

# 数据准备
n = 250
dates = pd.date_range('2024-01-02', periods=n, freq='B')

F1 = np.random.randn(n)
F2 = np.random.randn(n)
F3 = np.random.randn(n)

returns = pd.DataFrame({
    '铜': 0.7*F1 + 0.2*F2 + 0.3*F3 + np.random.randn(n)*0.3,
    '原油': 0.6*F1 + 0.1*F2 + 0.5*F3 + np.random.randn(n)*0.3,
    '黄金': -0.3*F1 + 0.8*F2 + 0.1*F3 + np.random.randn(n)*0.2,
    '白银': -0.1*F1 + 0.6*F2 + 0.2*F3 + np.random.randn(n)*0.3,
    '农产品': 0.3*F1 + 0.1*F2 + 0.2*F3 + np.random.randn(n)*0.3,
    '天然气': 0.2*F1 + 0.0*F2 + 0.8*F3 + np.random.randn(n)*0.3
}, index=dates)

returns = returns / 100

# 综合报告
fig = plt.figure(figsize=(20, 16))
gs = fig.add_gridspec(3, 3, hspace=0.35, wspace=0.3)

# Panel 1: 累计收益走势
ax1 = fig.add_subplot(gs[0, :])
cumulative = (1 + returns).cumprod()
for col in cumulative.columns:
    ax1.plot(cumulative.index, cumulative[col], linewidth=1.5, label=col)
ax1.axhline(y=1, color='gray', linestyle='--', alpha=0.5)
ax1.set_title('大宗商品ETF累计收益走势（2024年）', fontsize=16, fontweight='bold')
ax1.set_ylabel('累计净值')
ax1.legend(loc='upper left', ncol=6, fontsize=10)
ax1.grid(True, alpha=0.3)

# Panel 2: 箱线图
ax2 = fig.add_subplot(gs[1, 0])
```

```python
from sklearn.datasets import load_iris
```
