# 数字课程项目建设报告

本项目将现有三维知识空间升级为静态数字课程平台，保留原图谱工程与课程资料，发布目录单独维护。

## 已实现范围

- 首页、12章独立页面、方法导航、Python 实验、案例库、数据集、资源检索和关于课程。
- 111节点、199关系的Three.js图谱与课程资源页双向导航；原来源定位仍可核对。
- 12章讲义、12份PPTX及文本预览、12份清理后的原Notebook阅读参考、12组新编形成性练习、6条参考书目。
- 9个新编离线教学实验，分别覆盖PCA、FA、聚类、判别、回归、Logistic、CCA、CA与综合评价；固定种子模拟数据、代码、Notebook、字段说明和案例相互关联。
- 静态预览在构建阶段生成；Notebook源码被转义后展示，不在网站执行代码。
- GitHub Pages hash路由、相对资源地址、自动构建工作流、文件与隐私审计。

## 材料处理

课程资料按使用范围确认、隐私排除和可部署性分开处理。原课件采用副本清理身份元数据；原Notebook移除运行输出、执行计数、身份元数据和本机路径，作为阅读参考保留。仅新编实验标记执行状态，原课程案例不宣称重跑。

完整扫描参考书约220 MB，本版提供书目信息与原知识卡阅读页码，未打包整本PDF。原Excel工作簿未整体迁移，避免连带公开未逐表确认的数据；新编模拟案例配套数据可以独立下载。原图谱历史案例与新编模拟案例分别说明。

本地资料审查记录放在发布目录之外，避免暴露资料库结构和个人文件名。公开工程不包含学生管理目录、原始申报材料和私人来源日志。隐私审计发现值不写入报告。

## 验证口径

- 图谱结构与先修路径：自动测试及来源定位审计。
- 资源：登记文件存在、关联ID、静态部署路径、Notebook预览和内容审计。
- 浏览器：独立测试浏览器核对章节、讲义、Notebook、图谱入口和移动端；截图保留在本地 `output/playwright/`。
- 实验：执行状态与环境记录见课程实验报告，不将原Notebook内容检查称为复现。
- GitHub：只有远端仓库、Actions和线上页面实际检查完成后才登记为已发布。当前进度以最终交付说明为准。

## 尚存边界

未建设登录、数据库、AI答疑服务、学习行为后台或自动评分系统。原讲义中的历史代码、教学学时与全部数学推导尚未完成逐项学术审定；站点建设与结构审计不代表教学效果验证。课程总学时未因资源篇幅调整。

## 维护

修改课程文件后运行 `npm run prepare:course`，更新资源索引并检查来源说明。新资源应具有稳定ID、章节与知识节点关联、公开状态和真实执行状态。运行 `npm run build` 必须通过隐私与资源审计；人工复核以文件哈希记录，内容改变后需重新检查。

## 本轮验证结果（2026-09-13）

- 101项课程资源、134个原文件及预览链接均通过存在性与HTTP检查。
- 9项图谱自动测试、7项隐私审计测试、5项实验验收测试通过；9个新Notebook代码单元实际顺序运行通过，未保存运行输出。
- 6项桌面与移动端浏览器检查通过，无页面脚本异常。
- 干净目录通过 npm ci 安装锁定依赖，再独立完成生产构建及134个部署文件检查。
- 文本、Notebook与PPTX XML元数据审计通过；已知个人标识与本机用户路径扫描无命中。嵌入图片没有逐图OCR，自动审计不能代替对新增图片的内容复核。
- GitHub API查询目标新仓库返回不可访问（404）；当前没有远端提交、Actions成功记录或Pages上线记录。配置与本地源码包已经准备，实际发布等待仓库入口可用。
