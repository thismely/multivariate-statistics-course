单元 52 · code

H=sch.linkage(D); # 用于计算层次聚类,根据指定的方法（默认为 'single'）计算层次聚类的链接矩阵H,链接矩阵 H 包含了聚类过程中每一步的合并信息，包括被合并的簇及其之间的距离。
sch.dendrogram(H); # 绘制树状图。树状图是一种展示层次聚类结果的图形表示方式，通过树状图可以直观地观察到数据点的聚类过程和聚类结构。树状图的横轴表示样本，纵轴表示聚类过程中合并的距离。
