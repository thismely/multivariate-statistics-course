#### 2.1.1 Python的数据类型

**【业务场景引入】**

在开始处理多元统计数据之前，我们需要了解Python中存储数据的基本"容器"类型。类比一个大宗商品交易系统：
- **整型（int）**：合约代码（如CU2401表示2024年1月铜期货）

- **列表（list）**：一组有序的品种代码，如`['CU', 'AL', 'ZN']`

**（1）数值类型**

```python
# 基本函数定义
def sharpe_ratio(returns, rf=0.03):
    """
    计算Sharpe比率

    参数：
        returns: 收益率序列（列表或数组）
        rf: 无风险利率（默认3%）
    返回：
        Sharpe比率
    """
    import numpy as np
    excess_return = np.mean(returns) - rf
    volatility = np.std(returns, ddof=1)
    return excess_return / volatility if volatility > 0 else 0

# 使用
returns = [0.01, -0.02, 0.03, -0.01, 0.02, 0.015, -0.005]

print(f"Sharpe比率: {sr:.4f}")
```

### 2.3 多元数据的收集和整理

#### 2.3.1 数据收集方法

**【业务场景引入】**

多元统计数据的来源主要有以下几种：

| 数据来源 | 典型场景 | 数据特点 |
|----------|----------|----------|
| 问卷调查 | 消费者满意度、社会态度 | Likert量表、存在缺失值 |
| 实验观测 | 临床试验、农业实验 | 受控条件、需要随机化 |
| 数据库导出 | 金融交易、电商订单 | 数据量大、可能有异常值 |
| 网络爬虫 | 新闻舆情、社交媒体 | 非结构化、需要清洗 |
| 公开数据集 | 政府统计、学术数据 | 规范、但可能过时 |

**问卷调查中的Likert量表**：

在社会调查和市场研究中，最常用的数据收集工具是Likert量表（李克特量表）：

| 题项 | 非常不同意 | 不同意 | 一般 | 同意 | 非常同意 |
|------|-----------|--------|------|------|----------|
| 该品牌质量可靠 | 1 | 2 | 3 | 4 | 5 |
| 该品牌价格合理 | 1 | 2 | 3 | 4 | 5 |
| 我会推荐给朋友 | 1 | 2 | 3 | 4 | 5 |

编码注意事项：
- 正向题和逆向题需要统一方向（逆向题需反向计分）
- 缺失值需要特殊处理（如用NaN表示）

#### 2.3.2 缺失值处理

**（1）缺失值的类型与识别**

缺失值是多元数据分析中最常见的数据质量问题。根据缺失机制的不同，可以分为三类：

| 缺失类型 | 英文缩写 | 含义 | 例子 |
|----------|----------|------|------|
| 完全随机缺失 | MCAR | 缺失与任何变量无关 | 问卷丢失 |
| 随机缺失 | MAR | 缺失与其他观测变量有关 | 年轻人更不愿意填收入 |
| 非随机缺失 | MNAR | 缺失与缺失值本身有关 | 高收入者不愿填收入 |

**区分方法**：
- **MCAR**：缺失与所有变量都无关。可用Little's MCAR检验。
- **MAR**：缺失与其他已观测变量有关。如性别影响收入的缺失概率。
- **MNAR**：缺失与缺失值本身有关。如收入高的人更不愿意填写收入。

**处理策略**：

| 缺失类型 | 推荐处理方法 | 原因 |
|----------|-------------|------|
| MCAR | 删除法或均值插补 | 缺失完全随机，删除不会引入偏差 |
| MAR | 多重插补（MI） | 利用其他变量的信息进行插补 |
| MNAR | 选择模型或敏感性分析 | 需要专门的建模方法 |

**（2）异常值检测**

```python
def detect_outliers_zscore(data, threshold=3):
    """Z-score法检测异常值"""
    z_scores = np.abs((data - data.mean()) / data.std(ddof=1))
    return z_scores > threshold

def detect_outliers_iqr(data):
    """IQR法检测异常值"""
    Q1 = data.quantile(0.25)
    Q3 = data.quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR
    return (data < lower) | (data > upper)

# 示例
np.random.seed(42)
data = pd.Series(np.concatenate([np.random.normal(50, 10, 95), [120, 130, -20, 150, -30]]))

outliers_z = detect_outliers_zscore(data)
outliers_iqr = detect_outliers_iqr(data)

print(f"Z-score法异常值数量: {outliers_z.sum()}")
print(f"IQR法异常值数量: {outliers_iqr.sum()}")
print(f"IQR法异常值位置: {data[outliers_iqr].index.tolist()}")
```

#### 2.3.3 数据标准化

**【业务场景引入】**

在综合评价中，不同指标的量纲和数量级差异巨大。例如：
- GDP：单位是亿元，取值范围可能是[100, 40000]
- 人均收入：单位是万元，取值范围可能是[2, 10]
- 城镇化率：单位是%，取值范围可能是[30, 90]

如果直接将这些指标加权求和，GDP的数值会主导结果。**数据标准化**的目的就是消除量纲和数量级的差异。

**（1）Z-score标准化**

$$
x^* = \frac{x - \bar{x}}{s}
$$

- 标准化后均值为0，标准差为1
- 不受极值影响
- 结果可为负值（不便于后续加权求和）
- 适用于：聚类分析、主成分分析、回归分析

**（2）极值标准化（Min-Max）**

$$
x^* = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
$$

- 标准化后取值范围为[0, 1]
- 对异常值敏感
- 结果非负（便于后续加权求和）
- 适用于：综合评价、TOPSIS法

**（3）逆向指标的处理**

对于"越小越好"的指标（如失业率、犯罪率），需要先反转方向：

$$
x^* = \frac{x_{\max} - x}{x_{\max} - x_{\min}}
$$

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

df = pd.DataFrame({
    '城市': ['A', 'B', 'C', 'D'],
    'GDP': [8000, 5000, 3000, 6000],
    '人均收入': [6.5, 4.2, 3.0, 5.5],
    '失业率': [3.2, 5.8, 8.5, 4.1],
    '教育投入': [500, 300, 200, 400],
    '绿化率': [45, 38, 42, 50]
})

# Z-score标准化
scaler_z = StandardScaler()
df_zscore = pd.DataFrame(
    scaler_z.fit_transform(df.iloc[:, 1:]),
    columns=df.columns[1:]
)
print("=== Z-score标准化 ===")
print(df_zscore.round(3))

# 极值标准化（区分正向和逆向指标）
X = df.iloc[:, 1:].values.astype(float)
X_minmax = np.zeros_like(X)

positive_cols = [0, 1, 3, 4]
negative_cols = [2]

for j in positive_cols:
    X_minmax[:, j] = (X[:, j] - X[:, j].min()) / (X[:, j].max() - X[:, j].min())
for j in negative_cols:
    X_minmax[:, j] = (X[:, j].max() - X[:, j]) / (X[:, j].max() - X[:, j].min())

df_minmax = pd.DataFrame(X_minmax, columns=df.columns[1:])
print("\n=== 极值标准化（失业率已反转）===")
print(df_minmax.round(3))
```

**偏度与峰度的含义**：
- **偏度=0**：对称分布
- **偏度>0**：右偏（右尾较长）

- **峰度=0**：与正态分布相同
- **峰度>0**：尖峰厚尾（极端事件更频繁）
- **峰度<0**：平峰薄尾

```python
import numpy as np

# ============================================================
n = 20
companies = [f'矿业公司{chr(65+i)}' for i in range(n)]

revenue = np.random.lognormal(5, 0.5, n) * 10
profit = revenue * np.random.uniform(0.05, 0.25, n)
debt_ratio = np.random.normal(50, 15, n)
cash_flow = profit * np.random.uniform(0.5, 2, n)
inventory_turnover = np.random.normal(6, 2, n)

for arr in [revenue, profit, debt_ratio, cash_flow, inventory_turnover]:
    mask = np.random.random(n) < 0.1
    arr[mask] = np.nan

debt_ratio[3] = 98
inventory_turnover[7] = -2

df = pd.DataFrame({
    '公司': companies,
    '营业收入': revenue,
    '净利润': profit,
    '资产负债率': debt_ratio,
    '经营现金流': cash_flow,
    '存货周转率': inventory_turnover

print("=== 原始数据概览 ===")
print(df.head(10))

# ============================================================

# ============================================================
print("\n=== 缺失值统计 ===")
missing = df.isnull().sum()
missing_pct = (missing / len(df) * 100).round(1)
missing_info = pd.DataFrame({'缺失数': missing, '缺失比例(%)': missing_pct})
print(missing_info[missing_info['缺失数'] > 0])

for col in numeric_cols:
    median_val = df_clean[col].median()
    df_clean[col] = df_clean[col].fillna(median_val)

print(f"\n插补后缺失值: {df_clean[numeric_cols].isnull().sum().sum()}")

# ============================================================
# Step 3: 异常值检测与处理
# ============================================================
print("\n=== 异常值检测（IQR法）===")
for col in numeric_cols:
    Q1 = df_clean[col].quantile(0.25)
    Q3 = df_clean[col].quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR
    outliers = ((df_clean[col] < lower) | (df_clean[col] > upper))
    if outliers.sum() > 0:
        print(f"  {col}: {outliers.sum()}个异常值, 范围=[{lower:.2f}, {upper:.2f}]")

# Winsorize处理
for col in numeric_cols:
    Q1 = df_clean[col].quantile(0.25)
    Q3 = df_clean[col].quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR
    df_clean[col] = df_clean[col].clip(lower, upper)

# ============================================================
# Step 4: 数据标准化
# ============================================================
scaler_z = StandardScaler()
X_zscore = scaler_z.fit_transform(df_clean[numeric_cols])
df_zscore = pd.DataFrame(X_zscore, columns=numeric_cols)

scaler_mm = MinMaxScaler()
X_minmax = scaler_mm.fit_transform(df_clean[numeric_cols])
df_minmax = pd.DataFrame(X_minmax, columns=numeric_cols)

print("\n=== Z-score标准化后描述统计 ===")
print(df_zscore.describe().round(3))

# ============================================================
# Step 5: 相关系数分析
# ============================================================
corr = df_clean[numeric_cols].corr()
print("\n=== 相关系数矩阵 ===")
print(corr.round(3))

# ============================================================

axes[0, 0].set_title('缺失值分布')

# 标准化前箱线图
df_clean[numeric_cols].boxplot(ax=axes[0, 1])
axes[0, 1].set_title('标准化前箱线图')
axes[0, 1].tick_params(axis='x', rotation=45)

# 相关系数热力图
sns.heatmap(corr, annot=True, fmt='.3f', cmap='RdBu_r', center=0,
            square=True, ax=axes[1, 0])
axes[1, 0].set_title('相关系数矩阵')

# 变异系数对比

axes[1, 1].tick_params(axis='x', rotation=45)
```
