# 明亮蓝橙课堂主题

用户选择：A 明亮蓝橙（2026-09-13）。

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面背景 | `#f3f7fc` | 浅蓝白底 |
| 内容卡片 | `#ffffff` | 讲义、表格、知识卡 |
| 正文 | `#17324d` | 深蓝文字 |
| 辅助文字 | `#496176` | 说明、标签 |
| 主色 | `#075dcc` | 导航、按钮、选中节点 |
| 主色浅底 | `#e5efff` | 选中项、公式区域 |
| 强调 | `#d96908` | 重点提示边框 |
| 提示文字 | `#884108` | 配合 `#fff4e5` 提示背景 |

门户与讲义使用 `src/course.css` 的课程语义变量，知识空间使用 `src/style.css` 的语义变量。三维雾色及非选中连线向浅色背景过渡，模块仍保留六种可区分色。主题变更不修改图谱关系和课程内容。
