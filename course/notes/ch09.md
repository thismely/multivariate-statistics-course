### 9.1 相关与回归概述

#### 9.1.1 相关关系与因果关系

**【业务场景引入】**

在大宗商品市场中，铜价和油价通常呈正相关。但这是否意味着"铜价上涨导致油价上涨"？

**答案是否定的**。相关不等于因果。铜价和油价的正相关可能是因为：
- 两者都受全球经济景气度的影响（第三变量）
- 两者都受美元指数的影响（第三变量）

**虚假相关**：两个变量之间的统计相关可能是由第三个变量（混杂因素）导致的。

**经典例子**：
- 冰淇淋销量与溺水事件正相关 → 真正的原因是"天气热"（第三变量）
- 鞋子大小与阅读能力正相关 → 真正的原因是"年龄"（第三变量）

#### 9.1.2 相关分析与回归分析的区别与联系

**相关分析**研究的是变量之间线性关联的强度和方向，回答的是"两个变量是否相关、相关程度如何"的问题。相关分析中变量是对等的，没有因变量和自变量之分。

**回归分析**研究的是变量之间的依存关系，回答的是"一个变量如何随另一个变量变化"的问题。回归分析中必须明确因变量（被解释变量）和自变量（解释变量）。

**联系**：
- 相关分析是回归分析的基础
- 在一元线性回归中，相关系数的平方等于决定系数
- 相关显著是回归有意义的必要条件

#### 9.1.3 回归分析的基本思想

回归分析的核心思想是：通过建立数学模型，描述因变量Y与一个或多个自变量X之间的数量关系。

**回归分析的主要内容**：
1. 建立回归方程
2. 检验回归方程的显著性
3. 利用回归方程进行预测和控制

**回归分析的应用领域**：
- 经济预测：GDP预测、消费预测
- 金融分析：股票收益率预测、风险评估
- 医学研究：药物剂量与疗效关系
- 工程应用：质量控制、工艺优化
- 社会科学：教育投入与成绩关系

### 9.2 简单相关分析

#### 9.2.1 Pearson相关系数

**（1）公式**

$$
r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum(x_i - \bar{x})^2 \cdot \sum(y_i - \bar{y})^2}} = \frac{S_{xy}}{S_x S_y}
$$

**各符号的含义**：
- $S_{xy}$：X和Y的样本协方差
- $S_x$：X的样本标准差
- $S_y$：Y的样本标准差

**取值范围**：$r \in [-1, 1]$

| $r$ 的范围 | 相关程度 | 含义 |
|-----------|---------|------|
| $0.8 \leq |r| \leq 1$ | 强相关 | 变量间关系密切 |
| $0.5 \leq |r| < 0.8$ | 中等相关 | 变量间有一定关系 |
| $0.3 \leq |r| < 0.5$ | 弱相关 | 变量间关系较弱 |
| $|r| < 0.3$ | 极弱相关 | 变量间几乎无线性关系 |

**（2）假设检验**

H0：总体相关系数 $\rho = 0$（无线性相关）

检验统计量：

$$
t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}} \sim t(n-2)
$$

$p < \alpha$ 则拒绝H0，认为相关显著。

**（3）相关系数的计算步骤**

第一步：计算各变量的均值 $\bar{x}$ 和 $\bar{y}$

第二步：计算离差乘积和 $\sum(x_i - \bar{x})(y_i - \bar{y})$

第三步：计算离差平方和 $\sum(x_i - \bar{x})^2$ 和 $\sum(y_i - \bar{y})^2$

第四步：代入公式计算r

**（4）手工计算示例**

假设有5组数据：

| X | 2 | 4 | 5 | 6 | 8 |
|---|---|---|---|---|---|
| Y | 3 | 5 | 6 | 7 | 9 |

计算过程：

$\bar{x} = (2+4+5+6+8)/5 = 5$

$\bar{y} = (3+5+6+7+9)/5 = 6$

$\sum(x_i - \bar{x})(y_i - \bar{y}) = (-3)(-3) + (-1)(-1) + 0 \times 0 + 1 \times 1 + 3 \times 3 = 9+1+0+1+9 = 20$

$\sum(x_i - \bar{x})^2 = 9+1+0+1+9 = 20$

$\sum(y_i - \bar{y})^2 = 9+1+0+1+9 = 20$

$r = 20/\sqrt{20 \times 20} = 20/20 = 1$

完全正相关！

**（6）相关系数的Python实现**

```python
import numpy as np
from scipy import stats

# 示例数据
x = np.array([2, 4, 5, 6, 8])
y = np.array([3, 5, 6, 7, 9])

# 方法1：使用numpy计算
r_numpy = np.corrcoef(x, y)[0, 1]
print(f"numpy计算的相关系数: {r_numpy:.4f}")

# 方法2：使用scipy进行假设检验
r_scipy, p_value = stats.pearsonr(x, y)
print(f"scipy计算的相关系数: {r_scipy:.4f}")
print(f"p值: {p_value:.6f}")

# 方法3：手动实现
def pearson_correlation(x, y):
    n = len(x)
    mean_x = np.mean(x)
    mean_y = np.mean(y)

    numerator = np.sum((x - mean_x) * (y - mean_y))
    denominator = np.sqrt(np.sum((x - mean_x)**2) * np.sum((y - mean_y)**2))

    return numerator / denominator

r_manual = pearson_correlation(x, y)
print(f"手动计算的相关系数: {r_manual:.4f}")
```

#### 9.2.2 Spearman秩相关系数

将数据转换为秩次后计算Pearson相关，适用于非正态分布数据或有序分类数据。

$$
r_s = 1 - \frac{6\sum d_i^2}{n(n^2-1)}
$$

其中 $d_i$ 为第 $i$ 对数据的秩次之差。

**Spearman秩相关系数的特点**：
1. 对数据的分布没有要求，属于非参数方法
2. 衡量的是单调关系，而非严格的线性关系
3. 对异常值不敏感
4. 适用于有序分类数据

**秩次的计算方法**：

当数据中没有重复值时，将数据从小到大排序，序号即为秩次。

当数据中有重复值时，取这些重复值秩次的平均值作为它们共同的秩次。

**示例**：

原始数据：3, 5, 5, 7, 9

排序后：3(1), 5(2), 5(3), 7(4), 9(5)

秩次：1, 2.5, 2.5, 4, 5（两个5的秩次取平均 (2+3)/2=2.5）

**Spearman秩相关的Python实现**

```python
import numpy as np
from scipy import stats

# 示例数据
x = np.array([2, 4, 5, 6, 8])
y = np.array([3, 5, 6, 7, 9])

# 方法1：使用scipy计算
r_s_scipy, p_value = stats.spearmanr(x, y)
print(f"Spearman秩相关系数: {r_s_scipy:.4f}")
print(f"p值: {p_value:.6f}")

# 方法2：手动计算
def spearman_correlation(x, y):
    n = len(x)

    # 计算秩次
    rank_x = stats.rankdata(x)
    rank_y = stats.rankdata(y)

    # 计算秩次之差
    d = rank_x - rank_y

    # 计算Spearman相关系数
    r_s = 1 - (6 * np.sum(d**2)) / (n * (n**2 - 1))

    return r_s

r_s_manual = spearman_correlation(x, y)
print(f"手动计算的Spearman秩相关系数: {r_s_manual:.4f}")
```

#### 9.2.3 Pearson与Spearman的比较

| 特征 | Pearson | Spearman |
|------|---------|----------|
| 数据要求 | 连续数据，正态分布 | 任意分布，可有序分类 |
| 衡量关系 | 线性关系 | 单调关系 |
| 对异常值 | 敏感 | 不敏感 |
| 计算基础 | 原始数据 | 秩次 |
| 适用场景 | 正态分布的连续数据 | 非正态数据、有序数据 |

**选择建议**：
- 数据满足正态分布时，优先使用Pearson
- 数据不满足正态分布或有异常值时，使用Spearman
- 有序分类数据只能使用Spearman

### 9.3 多元线性相关与回归

#### 9.3.1 偏相关系数

控制其他变量后，$X_i$ 和 $X_j$ 的净相关：

$$
r_{ij.k} = -\frac{p_{ij}}{\sqrt{p_{ii} p_{jj}}}
$$

其中 $P = R^{-1}$（相关矩阵的逆）。

**实际含义**：偏相关系数排除了其他变量的干扰，反映两个变量之间"纯粹"的相关关系。

**偏相关系数的计算步骤**：

第一步：计算相关系数矩阵R

第二步：求相关系数矩阵的逆矩阵 $P = R^{-1}$

第三步：根据公式计算偏相关系数

**示例**：

假设有三个变量X1, X2, X3，相关系数矩阵为：

$$
R = \begin{pmatrix} 1 & 0.8 & 0.6 \\ 0.8 & 1 & 0.5 \\ 0.6 & 0.5 & 1 \end{pmatrix}
$$

求X1和X2在控制X3后的偏相关系数。

第一步：求逆矩阵P

$$
P = R^{-1} = \begin{pmatrix} 3.472 & -2.222 & -0.972 \\ -2.222 & 2.778 & -0.278 \\ -0.972 & -0.278 & 1.389 \end{pmatrix}
$$

第二步：计算偏相关系数

$$
r_{12.3} = -\frac{p_{12}}{\sqrt{p_{11} p_{22}}} = -\frac{-2.222}{\sqrt{3.472 \times 2.778}} = \frac{2.222}{3.108} = 0.715
$$

**解释**：在控制X3后，X1和X2的偏相关系数为0.715，比简单相关系数0.8有所下降，说明X3对X1和X2的关系有一定的解释作用。

**偏相关系数的Python实现**

```python
import numpy as np
import pandas as pd

def partial_correlation(data, var1, var2, control_vars):
    """
    计算偏相关系数

    参数:
    data: DataFrame
    var1: 第一个变量名
    var2: 第二个变量名
    control_vars: 控制变量名列表

    返回:
    偏相关系数
    """
    # 获取所有相关变量
    all_vars = [var1, var2] + control_vars
    corr_matrix = data[all_vars].corr()

    # 求逆矩阵
    inv_matrix = np.linalg.inv(corr_matrix.values)

    # 计算偏相关系数
    idx1 = 0
    idx2 = 1
    p_ij = inv_matrix[idx1, idx2]
    p_ii = inv_matrix[idx1, idx1]
    p_jj = inv_matrix[idx2, idx2]

    partial_corr = -p_ij / np.sqrt(p_ii * p_jj)

    return partial_corr

# 示例数据
np.random.seed(42)
n = 100
x1 = np.random.randn(n)
x2 = 0.8 * x1 + np.random.randn(n) * 0.6
x3 = 0.5 * x1 + 0.3 * x2 + np.random.randn(n) * 0.7

data = pd.DataFrame({'X1': x1, 'X2': x2, 'X3': x3})

# 计算简单相关系数
print("=== 简单相关系数 ===")
print(data.corr().round(4))

# 计算偏相关系数
print("\n=== 偏相关系数 ===")
r_12_3 = partial_correlation(data, 'X1', 'X2', ['X3'])
print(f"X1和X2在控制X3后的偏相关系数: {r_12_3:.4f}")

r_13_2 = partial_correlation(data, 'X1', 'X3', ['X2'])
print(f"X1和X3在控制X2后的偏相关系数: {r_13_2:.4f}")

r_23_1 = partial_correlation(data, 'X2', 'X3', ['X1'])
print(f"X2和X3在控制X1后的偏相关系数: {r_23_1:.4f}")
```

#### 9.3.2 简单线性回归

**（1）模型**

$$
y = \beta_0 + \beta_1 x + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2)
$$

其中：
- $\beta_0$：截距（当x=0时y的期望值）
- $\beta_1$：斜率（x每增加1个单位，y的平均变化量）
- $\varepsilon$：随机误差项

**（2）最小二乘法推导**

目标函数（残差平方和）：

$$
Q = \sum_{i=1}^{n}(y_i - \beta_0 - \beta_1 x_i)^2
$$

对 $\beta_0$ 和 $\beta_1$ 求偏导令其为零：

$$
\frac{\partial Q}{\partial \beta_0} = -2\sum(y_i - \beta_0 - \beta_1 x_i) = 0
$$

$$
\frac{\partial Q}{\partial \beta_1} = -2\sum x_i(y_i - \beta_0 - \beta_1 x_i) = 0
$$

由第一个方程得：

$$
\sum y_i = n\beta_0 + \beta_1 \sum x_i
$$

$$
\bar{y} = \beta_0 + \beta_1 \bar{x}
$$

$$
\beta_0 = \bar{y} - \beta_1 \bar{x}
$$

代入第二个方程：

$$
\sum x_i y_i - (\bar{y} - \beta_1 \bar{x})\sum x_i - \beta_1 \sum x_i^2 = 0
$$

$$
\sum x_i y_i - n\bar{x}\bar{y} + \beta_1 n\bar{x}^2 - \beta_1 \sum x_i^2 = 0
$$

$$
\sum(x_i - \bar{x})(y_i - \bar{y}) = \beta_1 \sum(x_i - \bar{x})^2
$$

解得：

$$
\hat{\beta}_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2} = \frac{S_{xy}}{S_{xx}}
$$

$$
\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}
$$

**（3）回归系数的性质**

- $\hat{\beta}_0$ 和 $\hat{\beta}_1$ 是 $\beta_0$ 和 $\beta_1$ 的无偏估计
- $\hat{\beta}_1$ 的方差为 $Var(\hat{\beta}_1) = \frac{\sigma^2}{\sum(x_i - \bar{x})^2}$
- $\hat{\beta}_0$ 的方差为 $Var(\hat{\beta}_0) = \sigma^2[\frac{1}{n} + \frac{\bar{x}^2}{\sum(x_i - \bar{x})^2}]$

**（4）回归方程的检验**

**F检验**（方差分析）：

$$
SST = SSR + SSE
$$

其中：
- $SST = \sum(y_i - \bar{y})^2$：总平方和
- $SSR = \sum(\hat{y}_i - \bar{y})^2$：回归平方和
- $SSE = \sum(y_i - \hat{y}_i)^2$：残差平方和

$$
F = \frac{MSR}{MSE} = \frac{SSR/1}{SSE/(n-2)} \sim F(1, n-2)
$$

H0：$\beta_1 = 0$，$F > F_\alpha$ 则拒绝H0。

**t检验**：

$$
t = \frac{\hat{\beta}_1}{SE(\hat{\beta}_1)} \sim t(n-2)
$$

其中 $SE(\hat{\beta}_1) = \sqrt{\frac{MSE}{\sum(x_i - \bar{x})^2}}$

一元回归中 $t^2 = F$，两种检验等价。

**决定系数**：

$$
R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}
$$

一元回归中 $R^2 = r^2$。

**（5）简单线性回归的Python实现**

```python
import numpy as np
import pandas as pd

    n = len(x)
    mean_x = np.mean(x)
    mean_y = np.mean(y)

    numerator = np.sum((x - mean_x) * (y - mean_y))
```

#### 9.3.3 多元线性回归

**（1）模型**

$$
Y = X\beta + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2 I)
$$

$X$ 为 $n \times (p+1)$ 设计矩阵（第一列为1）。

展开形式：

$$
\begin{pmatrix} y_1 \\ y_2 \\ \vdots \\ y_n \end{pmatrix} = \begin{pmatrix} 1 & x_{11} & x_{12} & \cdots & x_{1p} \\ 1 & x_{21} & x_{22} & \cdots & x_{2p} \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 1 & x_{n1} & x_{n2} & \cdots & x_{np} \end{pmatrix} \begin{pmatrix} \beta_0 \\ \beta_1 \\ \vdots \\ \beta_p \end{pmatrix} + \begin{pmatrix} \varepsilon_1 \\ \varepsilon_2 \\ \vdots \\ \varepsilon_n \end{pmatrix}
$$

**（2）最小二乘估计**

$$
\hat{\beta} = (X^TX)^{-1}X^TY
$$

在Gauss-Markov条件下，$\hat{\beta}$ 是 $\beta$ 的最佳线性无偏估计（BLUE）。

**推导过程**：

残差平方和：

$$
Q = (Y - X\beta)^T(Y - X\beta)
$$

展开：

$$
Q = Y^TY - Y^TX\beta - \beta^TX^TY + \beta^TX^TX\beta
$$

$$
Q = Y^TY - 2\beta^TX^TY + \beta^TX^TX\beta
$$

对 $\beta$ 求导：

$$
\frac{\partial Q}{\partial \beta} = -2X^TY + 2X^TX\beta = 0
$$

解得：

$$
X^TX\hat{\beta} = X^TY
$$

$$
\hat{\beta} = (X^TX)^{-1}X^TY
$$

**（3）回归系数的方差**

$$
Var(\hat{\beta}) = \sigma^2 (X^TX)^{-1}
$$

$\sigma^2$ 的无偏估计为：

$$
\hat{\sigma}^2 = \frac{SSE}{n-p-1} = \frac{(Y-X\hat{\beta})^T(Y-X\hat{\beta})}{n-p-1}
$$

**（4）回归模型的五大假设**

| 假设 | 含义 | 检验方法 |
|------|------|----------|
| 线性 | $E(Y) = X\beta$ | 残差图 |
| 独立性 | $\text{Cov}(\varepsilon_i, \varepsilon_j) = 0$ | Durbin-Watson检验 |
| 正态性 | $\varepsilon \sim N(0, \sigma^2)$ | Q-Q图 |
| 等方差性 | $\text{Var}(\varepsilon_i) = \sigma^2$ | 残差vs拟合值图 |
| 无多重共线性 | 自变量间无高度相关 | VIF < 10 |

**假设1：线性**

因变量与自变量之间的关系是线性的。

检验方法：
- 残差vs拟合值图：应呈随机散布
- 残差vs自变量图：应呈随机散布

如果违反线性假设，可以考虑：
- 对变量进行变换（对数变换、平方根变换等）
- 添加多项式项
- 使用非线性回归

**假设2：独立性**

观测值之间相互独立，误差项之间不相关。

检验方法：
- Durbin-Watson检验：统计量接近2表示无自相关
- 残差序列图：应呈随机波动

如果违反独立性假设，可以考虑：
- 使用时间序列模型
- 使用广义最小二乘法（GLS）

**假设3：正态性**

误差项服从正态分布。

检验方法：
- Q-Q图：点应大致在对角线上
- Shapiro-Wilk检验
- Kolmogorov-Smirnov检验

如果违反正态性假设，可以考虑：
- 对变量进行变换
- 使用非参数方法
- 样本量足够大时，中心极限定理保证估计量的渐近正态性

**假设4：等方差性（同方差性）**

误差项的方差是常数，不随自变量的变化而变化。

检验方法：
- 残差vs拟合值图：残差的散布范围应大致相同
- Breusch-Pagan检验
- White检验

如果违反等方差假设，可以考虑：
- 使用加权最小二乘法（WLS）
- 对变量进行变换
- 使用稳健标准误

**假设5：无多重共线性**

自变量之间不存在高度线性相关。

检验方法：
- VIF检验：VIF < 10表示无严重共线性
- 条件数：条件数 < 30表示无严重共线性

如果存在多重共线性，可以考虑：
- 删除高度相关的变量
- 使用主成分回归
- 使用岭回归

**（5）方差膨胀因子**

$$
VIF_j = \frac{1}{1 - R_j^2}
$$

$R_j^2$ 为第 $j$ 个自变量对其他自变量回归的决定系数。VIF > 10 存在严重共线性。

**VIF的解释**：
- VIF = 1：完全无共线性
- 1 < VIF < 5：轻度共线性
- 5 < VIF < 10：中度共线性
- VIF > 10：严重共线性

**VIF的计算步骤**：

第一步：对每个自变量 $X_j$，用其他所有自变量对其进行回归，得到 $R_j^2$

第二步：计算 $VIF_j = 1/(1-R_j^2)$

**（6）多重共线性的后果**

- 回归系数的方差增大，估计不稳定
- 回归系数的符号可能与预期相反
- 单个回归系数的t检验不显著，但整体F检验显著
- 删除一个变量后，其他变量的系数变化很大

**（7）F检验和t检验在多元回归中的区别**

在一元回归中，F检验和t检验等价。但在多元回归中：

- F检验：检验回归方程整体是否显著，即所有自变量的系数是否同时为0
- t检验：检验单个自变量的系数是否显著，即该自变量是否对因变量有显著影响

可能的情况：
- F检验显著，但某些t检验不显著：存在多重共线性
- F检验不显著，t检验也不显著：模型整体无效
- F检验显著，所有t检验都显著：模型有效，所有自变量都有贡献

#### 9.3.4 回归诊断

**（1）残差分析**

残差定义：

$$
e_i = y_i - \hat{y}_i
$$

标准化残差：

$$
r_i = \frac{e_i}{\hat{\sigma}\sqrt{1-h_{ii}}}
$$

其中 $h_{ii}$ 是帽子矩阵 $H = X(X^TX)^{-1}X^T$ 的对角元素。

学生化残差：

$$
t_i = \frac{e_i}{\hat{\sigma}_{(i)}\sqrt{1-h_{ii}}}
$$

其中 $\hat{\sigma}_{(i)}$ 是删除第i个观测后估计的标准差。

**（2）异常值检测**

- 标准化残差绝对值 > 2：可能是异常值
- 标准化残差绝对值 > 3：很可能是异常值
- Cook距离 > 4/n：有影响的观测值
- 杠杆值 $h_{ii} > 2(p+1)/n$：高杠杆点

**（3）影响分析**

Cook距离：

$$
D_i = \frac{e_i^2}{(p+1)MSE} \cdot \frac{h_{ii}}{(1-h_{ii})^2}
$$

Cook距离衡量删除第i个观测后，所有拟合值变化的程度。

DFBETAS：

$$
DFBETAS_{j(i)} = \frac{\hat{\beta}_j - \hat{\beta}_{j(i)}}{SE(\hat{\beta}_j)}
$$

DFBETAS衡量删除第i个观测后，第j个回归系数的变化程度。

#### 9.3.5 回归预测

**（1）点预测**

给定新的自变量值 $x_0$，预测因变量：

$$
\hat{y}_0 = x_0^T\hat{\beta}
$$

**（2）区间估计**

置信区间（估计均值）：

$$
\hat{y}_0 \pm t_{\alpha/2, n-p-1} \cdot \hat{\sigma}\sqrt{x_0^T(X^TX)^{-1}x_0}
$$

预测区间（预测个体值）：

$$
\hat{y}_0 \pm t_{\alpha/2, n-p-1} \cdot \hat{\sigma}\sqrt{1 + x_0^T(X^TX)^{-1}x_0}
$$

**注意**：预测区间比置信区间更宽，因为个体值的变异比均值的变异更大。

#### 9.3.6 变量选择

**（1）变量选择的目的**

- 简化模型，提高解释性
- 避免过拟合
- 减少测量成本

**（2）变量选择的方法**

**全子集回归**：对所有可能的自变量子集进行回归，选择最优子集。

**逐步回归**：
- 前向选择：从空模型开始，逐步加入最显著的变量
- 后向消除：从全模型开始，逐步删除最不显著的变量
- 双向逐步：同时进行前向选择和后向消除

**（3）模型选择准则**

**AIC（赤池信息准则）**：

$$
AIC = n\ln(SSE/n) + 2(p+1)
$$

**BIC（贝叶斯信息准则）**：

$$
BIC = n\ln(SSE/n) + (p+1)\ln(n)
$$

**调整R²**：

$$
R_{adj}^2 = 1 - \frac{SSE/(n-p-1)}{SST/(n-1)}
$$

**选择原则**：
- AIC和BIC越小越好
- 调整R²越大越好
- BIC对模型复杂度的惩罚更重

```python
# ============================================================
# 全子集回归
# ============================================================
def get_best_subset(data, response_var, predictor_vars):
    """
    全子集回归，根据AIC选择最优子集
    """
    best_aic = float('inf')
    best_model = None
    best_vars = None
    results = []

    # 遍历所有可能的变量子集
    for k in range(1, len(predictor_vars) + 1):
        for subset in combinations(predictor_vars, k):
            X = sm.add_constant(data[list(subset)])
            model = sm.OLS(data[response_var], X).fit()

            results.append({
                '变量': list(subset),
                '变量数': k,
                'R²': model.rsquared,
                '调整R²': model.rsquared_adj,
                'AIC': model.aic,
                'BIC': model.bic
            })

            if model.aic < best_aic:
                best_aic = model.aic
                best_model = model
                best_vars = list(subset)

    return best_model, best_vars, pd.DataFrame(results)

predictor_vars = ['X1', 'X2', 'X3', 'X4', 'X5']
best_model, best_vars, results_df = get_best_subset(df, 'Y', predictor_vars)

print("\n=== 全子集回归结果（按AIC排序）===")
print(results_df.sort_values('AIC').head(10).to_string(index=False))

print(f"\n=== 最优模型 ===")
print(f"选择的变量: {best_vars}")
print(f"AIC: {best_model.aic:.4f}")
print(f"调整R²: {best_model.rsquared_adj:.4f}")
print(f"\n回归系数:")

# 前向选择法
# ============================================================
def forward_selection(data, response_var, predictor_vars, significance_level=0.05):
    """
    前向选择法
    """
    selected_vars = []
    remaining_vars = list(predictor_vars)

    while remaining_vars:
        best_pvalue = float('inf')
        best_var = None

        for var in remaining_vars:
            current_vars = selected_vars + [var]
            X = sm.add_constant(data[current_vars])
            model = sm.OLS(data[response_var], X).fit()

            # 获取最后一个变量的p值
            pvalue = model.pvalues[var]

            if pvalue < best_pvalue:
                best_pvalue = pvalue
                best_var = var

        if best_pvalue < significance_level:
            selected_vars.append(best_var)
            remaining_vars.remove(best_var)
            print(f"加入变量 {best_var}，p值 = {best_pvalue:.6f}")
        else:
            break

    return selected_vars

print("\n=== 前向选择法 ===")
selected_vars = forward_selection(df, 'Y', predictor_vars)
print(f"选择的变量: {selected_vars}")

# ============================================================
# 后向消除法
# ============================================================
def backward_elimination(data, response_var, predictor_vars, significance_level=0.05):
    """
    后向消除法
    """
    selected_vars = list(predictor_vars)

    while selected_vars:
        X = sm.add_constant(data[selected_vars])
        model = sm.OLS(data[response_var], X).fit()

        # 获取最大p值
        max_pvalue = model.pvalues[1:].max()  # 排除常数项
        max_var = model.pvalues[1:].idxmax()

        if max_pvalue > significance_level:
            selected_vars.remove(max_var)
            print(f"删除变量 {max_var}，p值 = {max_pvalue:.6f}")
        else:
            break

    return selected_vars

print("\n=== 后向消除法 ===")
selected_vars = backward_elimination(df, 'Y', predictor_vars)
print(f"选择的变量: {selected_vars}")
```

### 实战案例9-3：回归诊断完整实现

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
```

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import Ridge, RidgeCV
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False
np.random.seed(42)

# ============================================================
# 数据准备
# ============================================================
n = 100
x1 = np.random.randn(n)
x2 = 0.9 * x1 + np.random.randn(n) * 0.3
x3 = np.random.randn(n)
x4 = 0.8 * x1 + 0.5 * x2 + np.random.randn(n) * 0.4

y = 2 + 3*x1 + 1.5*x2 + 2*x3 + 0.5*x4 + np.random.randn(n) * 0.5

X = np.column_stack([x1, x2, x3, x4])

# ============================================================
# 数据标准化
# ============================================================
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# ============================================================
# 岭回归
# ============================================================
# 选择不同的alpha值
alphas = [0.001, 0.01, 0.1, 1, 10, 100]

ridge_coefs = []
for alpha in alphas:
    ridge = Ridge(alpha=alpha)
    ridge.fit(X_scaled, y)
    ridge_coefs.append(ridge.coef_)

ridge_coefs = np.array(ridge_coefs)

# ============================================================
# 岭迹图
# ============================================================
plt.figure(figsize=(10, 6))
for i in range(4):
    plt.plot(alphas, ridge_coefs[:, i], marker='o', label=f'X{i+1}')

plt.xscale('log')
plt.xlabel('alpha (对数尺度)')
plt.ylabel('回归系数')
plt.title('岭迹图')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# ============================================================
# 交叉验证选择最优alpha
# ============================================================
ridge_cv = RidgeCV(alphas=np.logspace(-3, 3, 100), cv=5)
ridge_cv.fit(X_scaled, y)

print(f"最优alpha: {ridge_cv.alpha_:.4f}")
print(f"最优模型系数: {ridge_cv.coef_}")
print(f"最优模型截距: {ridge_cv.intercept_:.4f}")

# ============================================================
# 比较普通最小二乘和岭回归
# ============================================================
from sklearn.linear_model import LinearRegression

# 普通最小二乘
ols = LinearRegression()
ols.fit(X_scaled, y)

print("\n=== 系数比较 ===")
print(f"{'变量':<10} {'OLS系数':<15} {'岭回归系数':<15}")
print("-" * 40)
for i in range(4):
    print(f"X{i+1:<10} {ols.coef_[i]:<15.4f} {ridge_cv.coef_[i]:<15.4f}")

# 交叉验证分数比较
# ============================================================
ols_scores = cross_val_score(LinearRegression(), X_scaled, y, cv=5, scoring='r2')

print(f"\n=== 交叉验证R²分数 ===")
```

```python
axes[0].scatter(y_train, y_train_pred, alpha=0.6)
axes[0].plot([y_train.min(), y_train.max()], [y_train.min(), y_train.max()], 'r--', linewidth=2)
axes[0].set_xlabel('实际值')
axes[0].set_ylabel('预测值')
axes[0].set_title(f'训练集 (R²={train_r2:.3f})')

# 测试集
axes[1].scatter(y_test, y_test_pred, alpha=0.6)
axes[1].plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], 'r--', linewidth=2)
axes[1].set_xlabel('实际值')
axes[1].set_ylabel('预测值')
axes[1].set_title(f'测试集 (R²={test_r2:.3f})')

plt.tight_layout()
plt.show()

# ============================================================
# 9. 结果解释
# ============================================================
print("\n" + "=" * 60)
print("9. 结果解释")
print("=" * 60)

print("\n回归方程:")
print(f"房价 = {model.params[0]:.2f}", end="")
for i, var in enumerate(X.columns):
    coef = model.params[i+1]
    if coef >= 0:
        print(f" + {coef:.2f} × {var}", end="")
    else:
        print(f" - {abs(coef):.2f} × {var}", end="")

print("\n\n系数解释:")
for i, var in enumerate(X.columns):
    coef = model.params[i+1]
    pval = model.pvalues[i+1]
    sig = "***" if pval < 0.001 else "**" if pval < 0.01 else "*" if pval < 0.05 else ""
    print(f"{var}: 系数={coef:.4f}, p值={pval:.6f} {sig}")

print(f"\n模型整体检验:")
print(f"F统计量: {model.fvalue:.4f}")
print(f"F检验p值: {model.f_pvalue:.6f}")
print(f"R²: {model.rsquared:.4f}")
print(f"调整R²: {model.rsquared_adj:.4f}")
```

## 本章小结

| 知识点 | 核心内容 | 关键公式 |
|--------|----------|----------|
| Pearson相关系数 | 线性相关程度 | $r = S_{xy}/(S_x S_y)$ |
| Spearman秩相关 | 单调相关程度 | $r_s = 1 - 6\sum d_i^2/[n(n^2-1)]$ |
| 偏相关系数 | 控制其他变量后的净相关 | $r_{ij.k} = -p_{ij}/\sqrt{p_{ii}p_{jj}}$ |
| 相关系数检验 | H0: ρ=0 | $t = r\sqrt{n-2}/\sqrt{1-r^2}$ |
| 最小二乘法 | 最小化残差平方和 | $\hat{\beta} = (X^TX)^{-1}X^TY$ |
| F检验 | 回归方程整体显著性 | $F = MSR/MSE$ |
| t检验 | 回归系数显著性 | $t = \hat{\beta}/SE(\hat{\beta})$ |
| R² | 决定系数 | $R^2 = SSR/SST$ |
| 调整R² | 考虑变量数的决定系数 | $R_{adj}^2 = 1 - [SSE/(n-p-1)]/[SST/(n-1)]$ |
| VIF | 多重共线性检验 | $VIF = 1/(1-R_j^2)$ |
| AIC | 赤池信息准则 | $AIC = n\ln(SSE/n) + 2(p+1)$ |
| BIC | 贝叶斯信息准则 | $BIC = n\ln(SSE/n) + (p+1)\ln(n)$ |
| Cook距离 | 影响点诊断 | $D_i = e_i^2 h_{ii}/[(p+1)MSE(1-h_{ii})^2]$ |
| Durbin-Watson | 自相关检验 | $DW = \sum(e_i-e_{i-1})^2/\sum e_i^2$ |

## 扩展阅读

### 1. 广义线性模型

当因变量不满足正态分布假设时，可以使用广义线性模型（GLM）：

- 逻辑回归：因变量为二分类变量
- 泊松回归：因变量为计数变量
- Gamma回归：因变量为正的连续变量

### 2. 非参数回归

当变量之间的关系不是线性时，可以使用非参数回归：

- 核回归
- 局部多项式回归
- 样条回归

### 3. 正则化方法

为了解决过拟合和多重共线性问题，可以使用正则化方法：

- 岭回归（L2正则化）
- Lasso回归（L1正态化）
- 弹性网络（L1+L2正则化）

### 4. 贝叶斯回归

贝叶斯回归将回归系数视为随机变量，通过先验分布和似然函数得到后验分布：

- 可以融入先验信息
- 可以得到参数的不确定性估计
- 适合小样本情况
